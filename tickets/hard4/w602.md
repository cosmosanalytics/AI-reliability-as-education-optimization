Bug report: when a user config overrides one nested setting, the other settings next to it disappear, and setting an environment override to "false" still turns the feature on. Find the cause and fix it. Environment strings: true/yes/on/1 are True, false/no/off/0 are False (any case, spaces ignored), plain integers become int, decimals float, empty or null/none become None, anything else stays a stripped string. A None in the override removes the key. Run the test-suite in tests/ to see what currently fails. The visible tests cover only part of what is expected: a larger hidden suite of the same kind will also be run, so fix the underlying causes, not just the visible failures. Do not change the tests.
