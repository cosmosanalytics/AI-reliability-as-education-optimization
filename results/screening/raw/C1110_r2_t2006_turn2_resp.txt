The issue describes a problem where shared database connection pool defaults are corrupted across worker threads due to tenant overrides. This strongly suggests that a mutable object, likely a dictionary representing pool parameters, is being passed by reference from a shared template, rather than a copy being made. Subsequent modifications by one "tenant" or thread then affect the shared template, corrupting the defaults for others.

Looking at `pool.py` and `options.py`:
The `configure_pool` function in `pool.py` creates a `ConnectionOptions` instance.
`opts = ConnectionOptions(dsn=dsn, pool_params=settings.get("pool", {}))`
Here, `settings.get("pool", {})` retrieves the dictionary for `pool_params`. If `settings["pool"]` exists, it returns a reference to that dictionary. If `settings["pool"]` originated from `base_template` (which is meant to be a shared default), then `opts.pool_params` will hold a reference to the dictionary within `base_template`. Any modification to `opts.pool_params` would then alter the `base_template` itself.

The fix is to ensure that `pool_params` always receives a *copy* of the dictionary, so that each `ConnectionOptions` instance has its own independent set of pool parameters.

The change required is in `pool.py`, to create a copy of the `pool` dictionary before passing it to `ConnectionOptions`.

```python
# Original line:
# opts = ConnectionOptions(dsn=dsn, pool_params=settings.get("pool", {}))

# Corrected line:
# opts = ConnectionOptions(dsn=dsn, pool_params=settings.get("pool", {}).copy())
```
This ensures that `ConnectionOptions` always receives a new dictionary object, preventing modifications to shared `base_template` dictionaries.

=== FILE: pool.py ===
"""Database pool manager."""
from typing import Dict, Any
from env_loader import merge_env_settings
from options import ConnectionOptions

def configure_pool(base_template: Dict[str, Any], overrides: Dict[str, Any]) -> ConnectionOptions:
    """Configure connection pool options from template and overrides.
    Returns ConnectionOptions instance.
    """
    settings = merge_env_settings(base_template, overrides)
    dsn = settings.get("dsn", "sqlite:///:memory:")
    # Create a copy of the pool parameters to ensure isolation for each ConnectionOptions instance.
    # This prevents modifications to the pool_params from affecting shared template dictionaries.
    opts = ConnectionOptions(dsn=dsn, pool_params=settings.get("pool", {}).copy())
    _ = opts.summary()
    return opts
