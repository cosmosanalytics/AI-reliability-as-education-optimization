Let's consider the phrase "nearest rank" and how it's often implemented.
A percentile rank `R` for a value `x` in a sorted list of `N` values is `100 * (C - 0.5) / N` where `C` is count of values less than or equal to `x`.
To find the value for a given percentile `P`:
1. Calculate `k = P * N / 100`.
2. If `k` is an integer, the percentile is the average of the `k`-th and `k+1`-th values (1-indexed). Or, simply the `k`-th value depending on definition.
3. If `k` is not an integer, the percentile is the `ceil(k)`-th value (1-indexed).

The `idx = int(round((p / 100.0) * (n - 1)))` formula is common, but `round` can be tricky with `.5`.

`idx = int(math.ceil((p / 100.0) * n)) - 1`.
This formula calculates a 1-based rank by `(p/100)*n`, rounds it up (to get the "nearest rank"), and then converts to a 0-based index.
It needs to handle edge cases `p=0` and `p=100`.

If `p=100`: `rank_float = n`. `math.ceil(n) = n`. `idx = n - 1`. This is correct (last element).

To fix `p=0` and ensure `idx` is within bounds:
`rank = (p / 100.0) * n`
`idx = int(math.ceil(rank)) - 1`
`idx = max(0, idx)` (to handle `p=0` case, ensuring `idx` is at least 0)
`idx = min(n - 1, idx)` (to handle `p` slightly > 100, or floating point issues)

So the formula becomes:
```python

    idx = int(math.ceil(rank_float)) - 1

def compute_rpc_percentile(series: RpcSeries, p: float) -> float:
    """Calculates SLA percentile for RPC responses.

    Uses the "nearest rank" method (N*P/100) for percentile calculation,
    which is common for discrete data and matches the behavior of some
    telemetry systems.
    """
    vals = series.durations()
    if not vals:
        raise ValueError("No RPC samples available")
    s = sorted(vals)
    n = len(s)

    # Calculate rank using the formula (p/100) * n
    rank_float = (p / 100.0) * n
    
    # Round up to the nearest integer to get the rank.
    # If rank_float is exactly an integer, use it as is.
    # Otherwise, round up.
    if rank_float == int(rank_float):
        rank = int(rank_float)
    else:
        rank = math.ceil(rank_float)

    # Ensure rank is at least 1 and at most n
    rank = max(1, min(n, rank))
    
    # The index in a 0-based list is rank - 1
    idx = rank - 1
    
    return float(s[idx])
```

def compute_rpc_percentile(series: RpcSeries, p: float) -> float:
    """Calculates SLA percentile for RPC responses.

    Uses the "nearest rank" method (R-1) for percentile calculation,
    which is common for discrete data and aligns with definitions used
    in many telemetry systems. This method calculates the rank `k = p * n / 100`,
    and the percentile is the value at index `ceil(k) - 1` (0-indexed).
    Special handling ensures `p=0` returns the minimum and `p=100` returns the maximum.
    """
    vals = series.durations()
    if not vals:
        raise ValueError("No RPC samples available")
    s = sorted(vals)
    n = len(s)

    # Calculate the rank using the formula k = (p / 100.0) * n
    # For a 0-indexed array, the rank corresponds to index + 1.
    # The "nearest rank" method (R-1) typically rounds up to find the rank.
    # If p=0, rank_float is 0, ceil(0) is 0. idx = -1. Clamp to 0.
    # If p=100, rank_float is n, ceil(n) is n. idx = n-1. Clamp to n-1.
    
    # Calculate rank_float
    rank_float = (p / 100.0) * n
    
    # Determine the 0-based index.
    # Use math.ceil to always round up the rank.
    # Then convert to 0-based index by subtracting 1.
    idx = int(math.ceil(rank_float)) - 1
    
    # Ensure the index is within the valid bounds [0, n-1].
    # This handles edge cases like p=0 (idx becomes -1, clamped to 0)
    # and p values slightly above 100 (idx could become n, clamped to n-1).
    idx = max(0, min(n - 1, idx))
    
    return float(s[idx])

def build_rpc_report(service_name: str, series: RpcSeries, p: float) -> Dict[str, Any]:
