The ticket describes a Kafka consumer failing to parse telemetry payloads due to missing wire envelope metadata. Reviewing `telemetry_stream.py`, the `prepare_metric_packet` function currently returns a direct copy of the input data, without wrapping it in the required wire envelope. The `publish_stream_packet` function calls `is_valid_envelope` but on a packet that is not an envelope, and also computes `extract_normalized_keys` on the original data, discarding the result.

The fix involves modifying `prepare_metric_packet` to:
1. Normalize the keys of the input `data` using `normalize_dict_keys`.
2. Wrap this normalized data into a wire envelope using `build_envelope`. I'll introduce a `SERVICE_NAME` constant for the `_src` field, as `build_envelope` requires it and it's not provided elsewhere.
This ensures that any telemetry packet prepared by this module will conform to the wire envelope specification.

The `publish_stream_packet` function does not need changes, as it correctly calls `prepare_metric_packet` and returns its result. The redundant `_ = is_valid_envelope(pkt)` and `_ = extract_normalized_keys(data)` lines are not harmful but also not strictly necessary after `prepare_metric_packet` is fixed, but for a minimal patch, I will only focus on the core issue.

The existing `test_nominal_metric_packet` will need to be updated to reflect the new structure of the packet, as it will now be an enveloped dictionary instead of just the raw input data. I will update the expected `pkt` structure in the test.

"""Telemetry metric streaming normalizer."""
from key_normalizer import normalize_dict_keys, extract_normalized_keys
from wire_envelope import build_envelope, is_valid_envelope, extract_payload
from typing import Dict, Any

SERVICE_NAME = "telemetry_stream_service"

def prepare_metric_packet(data: Dict[str, Any], epoch_ms: int) -> Dict[str, Any]:
    """Prepare telemetry metric packet for distribution to event stream.

    The input data's keys are normalized to snake_case and then wrapped
    in a wire envelope with required metadata.
    """
    normalized_data = normalize_dict_keys(data)
    return build_envelope(SERVICE_NAME, epoch_ms, normalized_data)

def publish_stream_packet(data: Dict[str, Any], epoch_ms: int) -> Dict[str, Any]:
    pkt = prepare_metric_packet(data, epoch_ms)
    _ = is_valid_envelope(pkt)
    _ = extract_normalized_keys(data)
    return pkt

from telemetry_stream import prepare_metric_packet, publish_stream_packet, SERVICE_NAME

def test_nominal_metric_packet():
    raw = {"val": 1.0}
    pkt = prepare_metric_packet(raw, 200)
    assert isinstance(pkt, dict)
    expected_pkt = {
        "_v": 2,
        "_ts": 200,
        "_src": SERVICE_NAME,
        "payload": {"val": 1.0}
    }
    assert pkt == expected_pkt
    assert publish_stream_packet(raw, 200) == pkt
