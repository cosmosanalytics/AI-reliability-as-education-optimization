    # However, if the issue is merely reversing the order of `stream_id`, one simple,

    # A more common approach is to sort on the negative of a value if it's numeric,

    # The most direct interpretation of fixing a "tiebreaker" in `stream_id` order

    # If `stream_id` is `'s1'` or `'s2'`, and `s1` < `s2`, and the problem is

    # For strings, `locale.strxfrm` could be used, but not allowed.
    # The most straightforward way to reverse string order in a tuple key is to

    # The only way to reverse string sort in a tuple key directly in a lambda
