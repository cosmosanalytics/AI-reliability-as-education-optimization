           if not latencies:
               raise ValueError("No latency records")
           s = sorted(latencies)

           if q < 0.0: q = 0.0
           if q > 100.0: q = 100.0

           # However, instead of linear interpolation, we take the value at the
           # floored index to ensure compliance with SLA expecting lower values
           # when interpolation would yield a higher value.

           # for the calculated index.
           idx = (q / 100.0) * (n - 1)

           # Ensure idx is within valid bounds [0, n-1]
           if idx < 0:
               return float(s[0])
           if idx >= n - 1: # If idx is n-1 or greater, return the last element
               return float(s[n - 1])

           # Take the value at the floored index
           low_idx = int(math.floor(idx))
           return float(s[low_idx])

    This function calculates the q-th percentile of a list of latencies.
    It uses a method similar to `numpy.percentile` with `interpolation='lower'`.
    Specifically, it calculates the rank index `idx = (q / 100.0) * (n - 1)`.
    Instead of linearly interpolating between the two closest data points,
    it returns the data point at the floor of this index. This ensures that
    the reported percentile value is always one of the actual data points
    or the lower bound of an interpolated range, which is often desired
    in SLA compliance reporting to be more conservative.

    The change resolves an incident where SLA audit reports disagreed on
    latency percentiles, specifically an assertion failure where the calculated
    value was higher than the expected value (e.g., 45.0 vs 40.0). By picking
    the value at the floored index, we ensure that such interpolations
    that push the value higher are avoided.
    """
    if not latencies:
        raise ValueError("No latency records")

    s = sorted(latencies)
    n = len(s)

    # Handle edge cases for q
    # Clamp q between 0 and 100 to avoid out-of-bounds index calculations
    if q < 0.0:
        q = 0.0
    if q > 100.0:
        q = 100.0

    # Calculate the fractional index for the percentile.
    # This formula (q/100) * (n-1) correctly maps 0% to s[0] and 100% to s[n-1].
    idx = (q / 100.0) * (n - 1)

    # Determine the lower bound index.
    # For a percentile, if the index is fractional, we typically take the
    # value at the floor of the index for a 'lower' interpolation.
    # This ensures that the reported percentile is never higher than
    # what's strictly necessary if an interpolation would push it up.
    low_idx = int(math.floor(idx))

    # Ensure low_idx is within valid bounds [0, n-1]
    # This handles cases where q=0 (idx=0) or q=100 (idx=n-1)
    # and also protects against any floating point inaccuracies near boundaries.
    if low_idx < 0:
        low_idx = 0
    elif low_idx >= n: # Should ideally be n-1 for idx=(n-1)
        low_idx = n - 1

    return float(s[low_idx])
