    # One common method for calculating quantiles, often used by systems that prioritize

    # Let's try a definition where the index is `(n * q / 100.0)`.
    # If `idx` is an integer, use `s[idx-1]`.
    # If `idx` is not an integer, use `s[floor(idx)]`.

    # `k = int(idx_float)`
    # If `idx_float == k`: return `(s[k-1] + s[k]) / 2` (for 1-based index)

    # However, if the audit expects 40.0 for 70th percentile of `[10,20,30,40,50,60]`,

    # This would mean the effective index should be 3.
    # How to get an index of 3 from `q=70, n=6`?
    # `idx = (q / 100.0) * (n - 1)` gives 3.5.

    # And then the interpolation logic needs to be adjusted.
    # The `idx = (q / 100.0) * (n - 1)` is the most common.
    # The only way to get 40.0 for `q=70` from `[10,20,30,40,50,60]` is if the index was `3`.

    # `k = int(round(q/100 * n))`

    if not latencies:
        raise ValueError("No latency records")
    s = sorted(latencies)
    n = len(s)

    # Method R-3: Nearest Rank (used by some statistical packages for discrete percentiles)
    # This method calculates the rank and picks the value at that rank.
    # It avoids interpolation, which might be the source of disagreement with audit reports.
    # For a percentile q (0-100), the 1-based rank is k = round(q/100 * n).
    # The value is then s[k-1] (for 0-based index).
    # Handle edge cases for q=0 and q=100.
    if q < 0.0 or q > 100.0:
        raise ValueError("Quantile must be between 0 and 100")

    if n == 1:
        return float(s[0])

    # Convert q to a proportion (0 to 1)
    p = q / 100.0

    # Calculate the 1-based rank
    # Note: `round()` in Python 3 uses "round half to even" for .5.
    # `math.floor(x + 0.5)` can be used for "round half up".
    # However, for percentile ranks, usually standard rounding is sufficient.
    # Let's use `round()` as it's common.
    k = round(p * n)

    # Adjust rank to be 0-based index
    if k <= 0:
        index = 0
    elif k >= n:
        index = n - 1
    else:
        index = int(k) - 1 # k is 1-based, so subtract 1 for 0-based index

    return float(s[index])
