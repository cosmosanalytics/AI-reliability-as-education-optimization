## Example 1: Monetary Calculation and Banker's Rounding (Family: `money_rounding`)

### Ticket Description
**Issue:** `calculate_discounted_line(unit_price_cents, quantity, discount_pct)` produces ledger drift on invoice subtotals.
**Observed Behavior:** Applying a 15% discount to 3 items at 1275 cents ($12.75) yields incorrect fractional rounding when using standard floating-point operations. On exact half-cent thresholds (e.g. 191.25 cents discount), arithmetic truncation or standard float `round()` produces inconsistent totals that fail financial ledger audits.

### Root Cause Analysis
Floating-point arithmetic introduces representation error in decimal values. Furthermore, standard truncation or naive `int(x + 0.5)` rounds away from zero, introducing positive bias across aggregate transactions. House convention **Rule H02** dictates that all monetary computations must use integer cents or `decimal.Decimal` with banker's rounding (`ROUND_HALF_EVEN`), resolving ties at half-cents to the nearest even integer.

### Production Patch
```python
=== FILE: billing/discount.py ===
"""Invoice line item discount computation."""
from decimal import Decimal, ROUND_HALF_EVEN


def calculate_discounted_line(unit_price_cents: int, quantity: int, discount_pct: float) -> int:
    """Calculate discounted subtotal for an invoice line item.
    
    Args:
        unit_price_cents: Price per item in integer cents.
        quantity: Item count.
        discount_pct: Discount fraction between 0.0 and 1.0 (e.g. 0.15 for 15%).
        
    Returns:
        Gross subtotal in integer cents after discount, rounded using banker's rounding.
    """
    gross_cents = unit_price_cents * quantity
    d_gross = Decimal(str(gross_cents))
    d_pct = Decimal(str(discount_pct))
    
    # Calculate discount amount using banker's rounding
    discount_cents = int((d_gross * d_pct).quantize(Decimal("1"), rounding=ROUND_HALF_EVEN))
    return gross_cents - discount_cents
=== END ===
```

### Why This Fix Is Required
1. Converting integer cents and float parameters to `Decimal` strings eliminates IEEE 754 floating-point drift.
2. `quantize(Decimal("1"), rounding=ROUND_HALF_EVEN)` enforces strict banker's rounding (Rule H02), ensuring statistical balance and parity with external accounting ledgers.
3. The function returns pure integer cents without mutating caller-supplied structures.

## Example 2: Deep Configuration Merging and Input Immutability (Family: `config_merge`)

### Ticket Description
**Issue:** `merge_tenant_routing(base_config, tenant_overrides)` corrupts global routing defaults across concurrent requests.
**Observed Behavior:** When a tenant overrides a nested retry policy (e.g. `{"network": {"retries": 5}}`), subsequent requests from other tenants inherit `retries: 5` instead of the system default `retries: 3`.

### Root Cause Analysis
The merging routine executed in-place dictionary updates: `base_config["network"].update(tenant_overrides["network"])`. Because `base_config["network"]` is a mutable nested reference, mutating it directly altered the shared template dictionary held by the caller. House convention **Rule H03** mandates that functions accepting mutable containers must never mutate arguments in place and must return newly allocated data structures.

### Production Patch
```python
=== FILE: routing/config.py ===
"""Tenant routing configuration aggregator."""
import copy
from typing import Dict, Any


def merge_tenant_routing(base_config: Dict[str, Any], tenant_overrides: Dict[str, Any]) -> Dict[str, Any]:
    """Merge tenant-specific overrides into base configuration without aliasing.
    
    Args:
        base_config: Default system routing settings.
        tenant_overrides: Specific overrides supplied by tenant.
        
    Returns:
        Newly allocated composite configuration dictionary.
    """
    merged = copy.deepcopy(base_config)
    for key, value in tenant_overrides.items():
        if key in merged and isinstance(merged[key], dict) and isinstance(value, dict):
            # Recursively deep-merge nested dictionaries
            merged[key] = copy.deepcopy(merged[key])
            merged[key].update(copy.deepcopy(value))
        else:
            merged[key] = copy.deepcopy(value)
    return merged
=== END ===
```

### Why This Fix Is Required
1. Performing defensive deep copies via `copy.deepcopy` prevents shared reference aliasing across nested mappings (Rule H03).
2. The caller's `base_config` object remains completely immutable, guaranteeing isolation across concurrent request contexts.
3. The function returns a newly constructed independent mapping.
